# dobrewoks1.github.io

Страницы для откликов и небольшие рабочие инструменты. Собрано в связке с Claude Code.

- `sellehome/` — страница-ответ на вакансию: база Telegram-каналов и чатов продавцов Ozon/WB с живыми метриками,
  оценкой и черновиками первых сообщений. Данные: `sellehome/channels.json`.
- `laffit/` — страница-ответ на вакансию менеджера Ozon Global / WB China (автозапчасти из Китая): калькулятор
  юнит-экономики realFBS/FBP с порогами комиссий, сверка отчёта площадки с выплатой в CNY (свой CSV разбирается
  в браузере), проверка карточки автозапчасти, шпаргалка по условиям площадок, план рабочего дня.
- `iruler/` — ответ на вакансию специалиста по n8n / Python для партнёра Яндекс Такси: сценарий n8n «сверка
  транзакций парка» (Fleet API → PostgreSQL → отчёт, журнал запусков, сценарий ошибок, перезапуск за дату),
  проверенный на n8n 1.123 с тестовым сервером вместо Fleet API (`iruler/n8n/`), и SQL-песочница на PGlite
  (PostgreSQL в браузере) с задачами по данным таксопарка.
- `feedheat/` — ответ на тестовое задание SDR / LinkedIn Outreach (FeedHeat): две гипотезы аутрича для вымышленного
  SaaS Reconly с ICP-фильтрами и сообщениями на английском (счётчик символов connection note, проверка на штампы),
  диагностика трёх кампаний по воронке с автоматическим поиском узкого места, модель «что если» с ползунками по
  этапам воронки и правила еженедельного разбора.
- `ozon-manager/` — ответ на вакансию менеджера Ozon (электроинструмент, товары для дома, кухонная техника,
  20–30 карточек): разбор воронки по карточкам неделя к неделе с выводами по срочности и текстом отчёта для
  созвона (своя выгрузка TSV разбирается в браузере), калькулятор достоверности теста обложки и журнал тестов,
  календарь запуска товара от дедлайна назад, сборка названия, проверка покрытия ключей и ТЗ дизайнеру,
  шпаргалка по кабинету, план на 30 дней.
- `tools/ozon_weekly.py` — недельный отчёт по карточкам с теми же правилами, что на странице `ozon-manager/`:
  Seller API (`/v1/analytics/data`, остатки, индекс цен), CSV-выгрузка или тестовые ответы
  `tools/sample_rf`. С живым кабинетом не запускался:
  `python tools/ozon_weekly.py --sample tools/sample_rf --week-end 2026-10-26 --out weekly.md`
- `contentfactory/` — ответ на вакансию ассистента по рассылкам (контент-завод: ИИ-ролики для селлеров): шесть
  источников селлеров по силе сигнала, проба на 14 реальных брендах с маркетплейсов (каналы проверены на t.me,
  `contentfactory/sellers.json`, каждому — черновик первого сообщения, ничего не отправлялось), конструктор первого
  сообщения с проверкой на «спамность» для Telegram, ответы на типовые реакции, структура Google Таблицы с экспортом
  CSV, калькулятор потока «сообщения → встречи → продажи», правила гигиены аккаунта, план первой недели.
- `tools/collect_tg.py` — сбор публичных данных о каналах с t.me (без API и логина, 1 запрос/с).
  `python tools/collect_tg.py tools/channels.txt sellehome/channels.json`
- `tools/ozon_global_daily.py` — утренняя сводка по кабинету Ozon через Seller API: отправления, которые ждут
  отгрузки, запас по SKU в днях, начисления за вчера. С живым кабинетом не запускался (нет ключа), работает на
  тестовых ответах той же формы: `python tools/ozon_global_daily.py --sample tools/sample --out digest.md`.

Данные взяты с публичных страниц на дату сбора и могут устареть. Тарифы площадок на страницах — ориентиры из
открытых источников, не оферта.
