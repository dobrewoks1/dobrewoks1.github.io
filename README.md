# dobrewoks1.github.io

Страницы для откликов и небольшие рабочие инструменты. Собрано в связке с Claude Code.

- `sellehome/` — страница-ответ на вакансию: база Telegram-каналов и чатов продавцов Ozon/WB с живыми метриками,
  оценкой и черновиками первых сообщений. Данные: `sellehome/channels.json`.
- `laffit/` — страница-ответ на вакансию менеджера Ozon Global / WB China (автозапчасти из Китая): калькулятор
  юнит-экономики realFBS/FBP с порогами комиссий, сверка отчёта площадки с выплатой в CNY (свой CSV разбирается
  в браузере), проверка карточки автозапчасти, шпаргалка по условиям площадок, план рабочего дня.
- `tools/collect_tg.py` — сбор публичных данных о каналах с t.me (без API и логина, 1 запрос/с).
  `python tools/collect_tg.py tools/channels.txt sellehome/channels.json`
- `tools/ozon_global_daily.py` — утренняя сводка по кабинету Ozon через Seller API: отправления, которые ждут
  отгрузки, запас по SKU в днях, начисления за вчера. С живым кабинетом не запускался (нет ключа), работает на
  тестовых ответах той же формы: `python tools/ozon_global_daily.py --sample tools/sample --out digest.md`.

Данные взяты с публичных страниц на дату сбора и могут устареть. Тарифы площадок на страницах — ориентиры из
открытых источников, не оферта.
